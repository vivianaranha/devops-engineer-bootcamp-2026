## Docker
https://docs.docker.com/

Current Docker documentation covers Docker Engine, Docker Build/BuildKit and Docker Compose. Modern Compose build options include provenance and SBOM attestations.

## Kubernetes
https://kubernetes.io/releases/

As of September 2026, Kubernetes 1.37.0 is the current upstream minor release. The project maintains the most recent three minor release branches.

## Terraform
https://developer.hashicorp.com/terraform

Current Terraform CLI documentation is on the 1.16.x line. HashiCorp's style guidance recommends `terraform fmt`, validation, version pinning, testing, careful state practices and secure credential handling.

## GitHub Actions
https://docs.github.com/actions

GitHub Actions workflows are YAML files stored in `.github/workflows`. Workflow permissions can be explicitly reduced, and reusable workflows, concurrency controls, environments and deployment protections are available.

## Prometheus

Prometheus 3.14.0 is the current release as of August 17, 2026.

## Grafana
