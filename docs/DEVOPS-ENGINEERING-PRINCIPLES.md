# DevOps Engineering Principles

**Created by School of AI**

1. Keep changes small and reviewable.
2. Automate repeatable validation.
3. Build artifacts once and promote them.
4. Use immutable versions/digests.
5. Minimize CI/CD permissions.
6. Keep secrets outside source and artifacts.
7. Use health checks to control rollout.
8. Make rollback routine, not heroic.
9. Treat infrastructure as code.
10. Monitor metrics, logs and traces.
11. Tie alerts to user impact and operator action.
12. Define SLOs and error budgets.
13. Secure the full software supply chain.
14. Prefer self-service golden paths over ticket queues.
15. Learn from incidents and improve the system.
