# Student Guide

**Created by School of AI**

Use this DevOps loop:

**Code → Validate → Build → Package → Secure → Deploy → Verify → Observe → Learn → Improve**

Every delivery project should show:
- source/version,
- automated tests,
- immutable artifact,
- release gate,
- deployment record,
- rollback,
- metrics/logs,
- runbook.
